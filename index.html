GitHub About

Overview

ATRNXA is a solo project focused on building and breaking computational systems from scratch. No high-level abstractions or API wrappers. Just raw code to figure out how things actually work.

Because this runs on limited consumer hardware, implementations prioritize architectural logic and structural clarity over hyper-optimized production scaling.

Disclaimer

Everything here is experimental, volatile, and entirely unaudited. It represents an iterative, flawed learning process.

Use for architectural reference, educational dissection, or personal exploration. If something breaks or leaks memory, fix it yourself.
